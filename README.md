# Deal Watch Media

Immutable public media assets used by Deal Watch publishing previews and readback.

## Safety rules

- Published application URLs pin a full 40-character Git commit SHA.
- Assets are generated from reviewed specifications and include adjacent provenance JSON.
- No credentials, customer data, private analytics, or mutable approval state belong here.
- Adding an asset does not authorize or perform a social post, comment, DM, purchase, or settlement.
